Falcon Tab — API Key Setup

🔑

Get Your Free API Keys

Falcon Tab uses two optional API keys to power AI Chat and daily quotes. Both are completely free to obtain. Follow the steps below — it takes less than 2 minutes each.

🤖

OpenRouter API Key

openrouter.ai

Used for: AI Chat
  1. 1
    Go to OpenRouter

    Open openrouter.ai in a new tab. Click Sign In in the top-right corner.

  2. 2
    Create a free account

    Sign up with Google, GitHub, or your email address. No credit card is required for the free tier — many powerful models are available at zero cost.

    💡 OpenRouter gives free credits on sign-up and supports models like Llama 3, Gemma, and Mistral at no charge.
  3. 3
    Open API Keys settings

    After signing in, click your profile avatar (top-right) → select Keys, or go directly to openrouter.ai/settings/keys.

  4. 4
    Create a new key

    Click the + Create Key button. Give it a name like "Falcon Tab". Leave the limit blank for unlimited usage (within free tier).

  5. 5
    Copy your key

    Your key starts with sk-or-.... Copy it immediately — it won't be shown again in full after you leave this page.

    ⚠️ Keep this key private. Do not share it publicly. It's stored locally in your browser extension only.
↗ Open OpenRouter Keys Page
📋 Where to paste it in Falcon Tab:
⚙️ Settings › AI & Features › OpenRouter API Key field › Paste & Save

Click the ⚙️ icon in the top-right of your new tab to open Settings, then paste your key in the OpenRouter API Key input.

💬

API Ninja Key

api-ninjas.com

Used for: Daily Quotes
  1. 1
    Go to API Ninjas

    Open api-ninjas.com in a new tab. Click Sign Up in the top-right.

  2. 2
    Create a free account

    Register with your email address. The free plan includes up to 10,000 API calls/month — more than enough for daily quotes. No credit card needed.

  3. 3
    Verify your email

    Check your inbox for a confirmation email from API Ninjas and click the verify link.

  4. 4
    Find your API key

    After logging in, go to your Profile page. Your API key is listed under the API Key section. Click Show API Key to reveal it.

    💡 The key is a long random string — no special prefix. Copy the entire value.
  5. 5
    Copy your key

    Click the copy button next to your key, or select it all and press Ctrl+C / ⌘C.

↗ Open API Ninjas Profile
📋 Where to paste it in Falcon Tab:
⚙️ Settings › AI & Features › API Ninjas Key field › Paste & Save

Click the ⚙️ icon in the top-right of your new tab to open Settings, then paste your key in the API Ninjas Key input to enable daily quotes.

Both keys are stored only in your browser's local extension storage — never sent to any third-party server other than the respective API providers.
Falcon Tab is open source and does not collect any personal data.
